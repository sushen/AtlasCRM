You are building the initial infrastructure for a private web application called **Atlas CRM**.

## Purpose

Atlas CRM is a lightweight WhatsApp lead/customer journey tracker.

I already have a dataset of WhatsApp phone numbers extracted from saved WhatsApp Business Web HTML. The saved source is from WhatsApp Web.

The purpose of Atlas CRM is to take those numbers and turn each one into a persistent lead/customer record.

I want to know the **journey of every WhatsApp contact**:

**Imported → Not Contacted → Contacted → Replied → Interested → Customer → Renewal / Follow-up**

The application should help me work through hundreds or eventually thousands of WhatsApp contacts without losing track of who I contacted and what happened.

## Required Technology

Keep the architecture deliberately simple.

Use:

- Vanilla HTML5
- Vanilla CSS3
- Vanilla JavaScript using ES modules
- Firebase
- Firebase Firestore as the database
- Firebase Authentication for private access
- Firebase Hosting if appropriate

Do NOT introduce:

- React
- Vue
- Angular
- TypeScript
- Node backend
- Express
- Supabase
- unnecessary frameworks

unless there is a genuine technical requirement.

## Important Architecture Principle

Atlas CRM does NOT control WhatsApp.

Do not scrape or modify WhatsApp Web.

Do not claim to know whether a WhatsApp message was actually sent, delivered, read, or replied to unless that information is manually recorded or later supplied by an official integration.

Atlas should manage the **business journey around the conversation**.

For each customer, provide an action that opens:

https://wa.me/<normalized-number>

Optionally allow a message to be prefilled.

Opening WhatsApp should create an activity such as:

`whatsapp_opened`

It must NOT automatically mark the message as successfully sent.

I should manually be able to mark:

- Message Sent
- Replied
- No Response
- Interested
- Not Interested
- Customer
- Follow Up
- Do Not Contact

## Phone Normalization

Bangladesh numbers may appear as:

```text

8801712345678
+8801712345678
```


Store a normalized representation that can be safely used for duplicate detection.
