==================================================
2. PROJECT IDENTITY
==================================================

Project name:

Atlas CRM

Atlas CRM is a private, lightweight CRM centered around managing WhatsApp leads/customers and tracking their journey.

Core conceptual journey:

WhatsApp Number
→ Imported Lead
→ Not Contacted
→ Contacted
→ Replied
→ Interested
→ Customer
→ Follow-up
→ Purchase / Subscription / Renewal

Current intended technology:

- HTML5
- CSS3
- Vanilla JavaScript
- ES Modules
- Firebase
- Firestore
- Firebase Authentication
- Firebase Hosting where appropriate

Do not introduce React, Vue, Angular, TypeScript, Express, or another major framework unless explicitly requested.

Atlas CRM is NOT WhatsApp.

WhatsApp remains an external communication system.

Atlas manages the customer/business journey surrounding those conversations.

Opening WhatsApp does not prove that a message was sent, delivered, read, or replied to.

Those events must be manually recorded unless a future official integration supplies reliable events.

ARCHITECTURAL RULES

Future agents MUST:

- inspect existing code before changing it
- read project documentation before substantial work
- preserve the framework-free architecture unless explicitly instructed otherwise
- keep UI, business logic, Firebase access and utilities separated
- preserve customer history

- treat "WhatsApp opened" as "message sent"
